# Phase6-STEP16 投稿後リロード + 先頭スクロール + Toast通知

## 概要

投稿成功後に一覧を再取得・先頭スクロールし、
Toast通知で投稿完了をユーザーに伝える。

## ディレクトリ構成（差分）

```
catroom/
├── src/
│   ├── hooks/
│   │   └── usePosts.ts       ← 変更（refreshPosts追加）
│   └── components/
│       └── Toast.tsx         ← 新規作成
└── App.tsx                   ← 変更（ScrollView ref・Toast表示）
```

---

## 投稿後フロー

```
「投稿する」押下
    ↓
画像アップロード（R2）+ POST /posts（DB保存）
    ↓
① setModalVisible(false)        モーダルを閉じる
    ↓
② refreshPosts()                GET /posts を再取得・state上書き
    ↓
③ scrollTo({ y: 0 })            フィード先頭へスクロール
    ↓
④ setToastVisible(true)         Toast通知を表示
    ↓
自分の投稿が先頭に表示される ✅
```

---

## fetchPosts と refreshPosts の違い

|                  | fetchPosts                 | refreshPosts                   |
| ---------------- | -------------------------- | ------------------------------ |
| 用途             | 初回取得・エラー時の再試行 | 投稿後の最新化                 |
| ローディング表示 | 全画面スピナー             | フィード上部バー（refreshing） |
| 失敗時           | エラー画面表示             | 既存データ維持（サイレント）   |
| state操作        | 上書き（offset リセット）  | 上書き（offset リセット）      |

---

## Toast仕様

| 機能           | 内容                                      |
| -------------- | ----------------------------------------- |
| 表示位置       | 画面上部・フィードに重ねる（zIndex: 999） |
| 表示トリガー   | 投稿成功後                                |
| 自動非表示     | 5秒後（`duration` で変更可）              |
| 残り時間表示   | オレンジのタイマーバーで視覚化            |
| 上スワイプ     | 40px以上で即閉じる                        |
| タップ         | PanResponderで検知・即閉じ                |
| アニメーション | フェードイン＋上からスライドイン          |

### Toastコンポーネントのprops

```ts
type Props = {
  message: string;
  visible: boolean;
  onHide: () => void;
  duration?: number;  // デフォルト 5000ms
};
```

### スワイプ閉じの閾値

```ts
// 上方向に40px以上スワイプ → 閉じる
if (gestureState.dy < -40) {
  hideToast()
}
```
