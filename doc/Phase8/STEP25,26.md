# STEP25 投稿通報機能

## 概要

不適切投稿をユーザーが匿名で通報できる機能を追加する。
通報が1件以上の投稿は一覧取得時に除外される。
通報後はカードがその場で非表示になりUXを損なわない。

## ディレクトリ構成（差分）

```
api/
└── src/
    ├── db/
    │   └── schema/
    │       └── reports.ts         ← 新規作成
    ├── routes/
    │   └── reports.ts             ← 新規作成
    └── routes/
        └── posts.ts               ← 変更（通報済み除外）

└── src/
    ├── components/
    │   ├── ReportModal.tsx        ← 新規作成
    │   └── CatCard.tsx            ← 変更（通報ボタン追加）
    └── lib/
        └── api.ts                 ← 変更（reportPost追加）
```

## DBスキーマ

### `post_reports` テーブル

| カラム       | 型          | 説明                          |
| ------------ | ----------- | ----------------------------- |
| `id`         | uuid        | PRIMARY KEY                   |
| `post_id`    | uuid        | 外部キー（posts.id・cascade） |
| `reason`     | varchar(20) | 通報理由                      |
| `created_at` | timestamp   | 通報日時                      |

### マイグレーション実行

```bash
cd api
npx drizzle-kit generate
npx drizzle-kit migrate
```

## 通報理由

| value       | 表示ラベル |
| ----------- | ---------- |
| `spam`      | スパム     |
| `not_cat`   | 猫ではない |
| `offensive` | 不快な画像 |
| `grotesque` | グロテスク |
| `other`     | その他     |

---

## API

### エンドポイント

```
POST /posts/:id/report
Content-Type: application/json

{ "reason": "spam" }
```

### レスポンス

```json
{ "success": true }
```

### 通報済み除外ロジック

```ts
// 通報が1件以上ある投稿IDを取得
const reportedPostIds = await db
  .selectDistinct({ postId: reports.postId })
  .from(reports)

// notInArray で除外して取得
.where(notInArray(posts.id, excludeIds))
```

## フロント設計

### 通報フロー

```
🚩ボタン押下
    ↓
ReportModal が開く
    ↓
通報理由をラジオボタンで選択
    ↓
「通報する」ボタン押下 → API送信
    ↓
✅ 完了メッセージ表示（1.5秒）
    ↓
モーダルを閉じる → CatCard が非表示
```

### 通報後のカード非表示

```ts
// CatCard 内
const [isReported, setIsReported] = useState(false)

if (isReported) return null  // 通報後は即非表示

// ReportModal の onReported コールバック
onReported={() => setIsReported(true)}
```

# STEP26 利用規約 + プライバシーポリシー

## 概要

サービス公開に最低限必要な法的ページを追加する。
Routerを使わずstateで画面切り替えを実装する。

## ディレクトリ構成（差分）

```
nyafeed/
└── src/
    ├── screens/
    │   ├── TermsScreen.tsx        ← 新規作成
    │   └── PrivacyScreen.tsx      ← 新規作成
    └── components/
        └── Footer.tsx             ← 新規作成
App.tsx                            ← 変更（画面切り替え・フッター追加）
```

---

## 画面切り替え設計

```ts
// Router禁止のためstateで管理
type Screen = 'feed' | 'terms' | 'privacy'

const [screen, setScreen] = useState<Screen>('feed')

// 利用規約 → setScreen('terms')
// プライバシー → setScreen('privacy')
// 戻る → setScreen('feed')
```

---

## ページ内容

### 利用規約（7条構成）

| 条項  | 内容                 |
| ----- | -------------------- |
| 第1条 | サービスの概要       |
| 第2条 | 禁止事項             |
| 第3条 | 投稿コンテンツの責任 |
| 第4条 | 運営の免責           |
| 第5条 | サービスの変更・終了 |
| 第6条 | 規約の変更           |
| 第7条 | 準拠法               |

### プライバシーポリシー（8項目）

| 項目 | 内容                                         |
| ---- | -------------------------------------------- |
| 1    | 収集する情報（アクセスログ・画像・コメント） |
| 2    | 画像データの保存（Cloudflare R2）            |
| 3    | アクセスログの利用目的                       |
| 4    | Cookieの使用（現時点では未使用）             |
| 5    | 第三者サービスの利用（R2・Neon・Vision API） |
| 6    | 情報の第三者提供                             |
| 7    | お問い合わせ                                 |
| 8    | ポリシーの変更                               |
