# Phase1-STEP4

## 状態管理の設計まとめ
```bash
App（useState × 2）
├── cats: Cat[]          → フィード全体（投稿追加で更新）
└── modalVisible: boolean → モーダル開閉
        ↓ propsで渡す
Header         → onPost（モーダルを開く）
PostModal      → onSubmit（新規Catを受け取りcatsに追加）
CatCard        → cat（表示のみ・変更なし）
```

## 投稿フロー
```bash
① ヘッダー「+ 投稿」押下
        ↓
② PostModal が開く（modalVisible: true）
        ↓
③ コメント入力 ＋ 画像選択（任意）
        ↓
④「投稿する」押下 → onSubmit(newCat)
        ↓
⑤ App の cats 先頭に newCat を追加
        ↓
⑥ モーダルを閉じる → フィード最上部に投稿が出現
```

## 起動確認
```bash
# Web専用で起動
npx expo start --web

# またはnpm scriptで起動
npm run web
```

## 動作確認

| 確認項目     | 期待動作                        |
| -------- | --------------------------- |
| 投稿ボタン    | ヘッダー右に「+ 投稿」オレンジボタンが表示される   |
| モーダル表示   | ボタン押下でボトムシート（モーダル）が開く       |
| 背景タップ    | オーバーレイタップでモーダルが閉じる          |
| 画像選択     | ファイル選択エリアタップでOS標準ダイアログが起動する |
| 画像プレビュー  | 選択後に画像プレビューが表示される           |
| 画像省略     | 未選択でもダミー画像で投稿可能             |
| コメント未入力  | 「投稿する」ボタンが無効化（薄く表示され押せない）   |
| バリデーション  | 空コメント時にエラーメッセージが表示される       |
| 文字数表示    | 入力中に `n / 100` が表示される       |
| 投稿完了     | 投稿後、フィード最上部に新カードが追加される      |
| リアクション動作 | 投稿したカードでもリアクション機能が正常に動作する   |
| UI崩れなし   | フィード・カード・モーダルのレイアウトが崩れない    |
