# Phase7-STEP23 リアクション数の曖昧表示

## 概要

リアクション数を正確な数値ではなく曖昧なラベルで表示する。
数字競争・承認欲求を弱め「かわいい猫を見る」体験を優先する。
DBは実数を保持し、フロントのみで変換する。

## ディレクトリ構成（差分）

```
nyafeed/
└── src/
    ├── lib/
    │   └── fuzzyCount.ts      ← 新規作成（曖昧変換関数）
    └── components/
        └── ReactionBar.tsx    ← 変更（曖昧表示に切り替え）
```

---

## 設計方針

```
DB        → 実数を保持（変更なし）
API       → 実数をそのまま返す（変更なし）
フロント   → calcTotalReactions で全リアクションの合計を計算
           → toFuzzyLabel で曖昧ラベルに変換して表示
           → 個別ボタンの数値は非表示
```

APIもDBも変更不要。フロント2ファイルのみの変更で完結する。

| 合計数 | 表示ラベル               | カラー                  |

| 5〜19  | 🐾 かなり吸われている     | オレンジ（#f97316）     |
| 20〜49 | 🐾 猫好き達が集まっている | レッド（#ef4444）       |

| 100〜  | 🐾 猫神クラス             | バイオレット（#7c3aed） |
